# Taiwan IC Power Prediction

## Project Overview

This project predicts the power consumption of a digital Integrated Circuit (IC) using Machine Learning.

## Features

- Verilog Full Adder Circuit
- Synthetic Dataset Generation
- Power and Delay Analysis
- Random Forest Machine Learning Model
- IC Power Consumption Prediction

## Technologies Used

- Python
- Verilog HDL
- Pandas
- NumPy
- Scikit-learn

## Project Structure

Taiwan_IC_Power_Prediction/

- dataset/
- verilog/
  - full_adder.v
  - full_adder_tb.v
- python/
  - generate_dataset.py
  - train_model.py

## Input Features

- A
- B
- Cin
- Sum
- Cout
- Switching Activity
- Transistor Count
- Delay

## Output

Predicted IC Power Consumption.
